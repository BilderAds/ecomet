# Session 2026-08-23-01 — Relaunch als Plattform

## Ziel

Kevin: die Website soll All-in-One-Plattform werden (Apps, deutsches Fulfillment,
Import), gleichzeitig Webapplikation mit den Shopify-Zahlen des Händlers, und
werbetauglich mit je einer Seite pro App. Dazu Umzug auf **e-comet.de**.

## Was gemacht wurde

**Geplant.** Spec in `docs/SPEC-23AUG26-RELAUNCH-PLATTFORM.md`, elf Abschnitte,
Zeiger in `README.md` und in `Projekte/Ecomet/LIESMICH.md`. Vier Blöcke, so
geschnitten, dass Block 1 an niemandem hängt.

**Gebaut, Block 1.** Aus dem Onepager wurden dreizehn Seiten plus eigene
404-Seite. Grundlage ist die dark-glass-Vorlage aus
`Website Builder/vorlagen/dark-glass/`, das CSS liegt als `src/app/darkglass.css`
im Projekt, umgefärbt auf Marken-Orange `#ff642c`, Grund und Fläche auf die
Werte aus dem ecomet-Baukasten (`kit.js`).

**Neu:** Startseite (zehn Blöcke), `/fulfillment/deutschland`,
`/fulfillment/china`, `/apps/dashboard`, `/apps/invoices`, `/apps/faelle`,
`/preise`, `/ueber-uns`, `/kontakt`, `/registrieren`, `/api/anfrage`,
`not-found`.

**Zahlen an einer Stelle:** `src/inhalte/zahlen.ts`, jede Zahl mit Feld
`geprueft` und `quelle`. Platzhalter sind als solche markiert.

**Formular ist echt:** `/api/anfrage` schreibt nach Supabase (Projekt
„ecomet website", Tabelle `anfrage`, RLS an, nur der Server schreibt über den
geheimen Schlüssel). Honigtopf gegen Maschinen.

## Entscheidungen

- **E: dark-glass statt App-Look für die Website.** Kevin am 23.08.: „das Design
  von skaile finde ich schon ganz geil mit diesem Glas Effekt". Passt zusammen,
  weil der App-Baukasten dieselbe Glasscheibe nutzt, nur dezenter.
- **E: Akzentfarbe auf Bedeutung reduziert.** Die Vorlage lässt sechs Icons,
  vier Nummern und alle Haken gleichzeitig leuchten. Ab jetzt trägt Orange nur
  Bühne, aktiven Schritt, Weiche, Hauptknopf und Fokus.
- **E: Registrierung ist ein Antrag, kein Selbstbedienungs-Konto.** Ehrlich so
  benannt, weil das Onboarding heute von Hand läuft.

## Lessons Learned

- **LL: Die Supabase Management API antwortet ohne User-Agent mit 403
  (Cloudflare 1010).** Mit `-H "User-Agent: curl/8.7.1"` geht es. Python
  urllib scheitert deshalb, curl klappt.
- **LL: Ein `.glass-btn` braucht `display:inline-block`, sobald er ein Link
  statt eines `<button>` ist.** Sonst kollabiert das Glas und der Knopf steht
  als nackter Text da. Ist beim ersten Screenshot aufgefallen.
- **LL: Eine offene Datei in TextEdit überschreibt Änderungen am Dateisystem.**
  Beim Korrigieren der `.env.local` zweimal passiert.

## Geprüft

keine Konsolenfehler. Jeder interne Link antwortet mit 200. Formular im echten
Lauf getestet, Prüfeintrag danach gelöscht. Blur-Test bestanden.
